# 시연 시나리오 (배포판, 5분)

- 사이트: https://gamsang-note.onrender.com
- 계정: 시연자 user01(민트초코), 친구 아닌 사람 user07(야간관람). 비밀번호는 로그인 화면 아래의 시연용 값

## 사전 준비 (시연 10분 전)
- 사이트를 열어 깨운다. 15분 동안 요청이 없으면 잠들고, 깨는 데 3~4분 걸린다. "Application loading"이 보이면 기다린다.
- user01로 미리 로그인해 둔다.
- 외부 검색어를 확인해 둔다: 영화 "인셉션", 책 "채식주의자"는 결과가 나온다. 공연은 지금 KOPIS에 결과가 나오는 제목을 하나 골라 둔다.
- 배포판은 쓴 내용을 되돌릴 수 없다. 시연에서 쓰는 기록·후기·댓글은 필요한 만큼만 쓴다.
- 쓰기 기능은 배포판에서 미리 시험하지 못했으므로, 리허설에서 한 번 실제로 해 보고 결과를 확인한다.

## 역할
- 발표: 말하는 사람 / 조작: 화면 담당. 팀에서 정한다.
- 사용자 전환 = 로그아웃 후 다른 계정으로 로그인.

## 시간표
| 시간 | 화면 | 조작 | 발표 멘트 요지 |
|---|---|---|---|
| 0:00~0:30 | 로그인 | user01로 로그인 | 영화·책·공연을 한곳에 기록하는 서비스. 비밀번호는 BCrypt 해시, 로그인은 서버 세션 |
| 0:30~1:30 | 작품 | 영화/책/공연 탭 → "인셉션" 검색 → 상세 → 기록 추가(봤어요, 별점) | 작품을 영화·책·공연 서브타입으로 나눔. TMDB·YES24·KOPIS에서 실제 작품 정보를 가져옴 |
| 1:30~2:20 | 내 기록 → 후기 | '보고 싶어요' 기록 하나에 후기 작성(공개 범위: 친구) | 후기를 저장하면 트리거가 기록을 '봤어요'로 자동 변경 |
| 2:20~3:00 | 후기 | 로그아웃 → user07로 로그인 → 후기 목록 | 친구가 아니어서 방금 쓴 '친구 공개' 후기가 보이지 않음(뷰 v_visible_review) |
| 3:00~3:30 | 후기 | 전체 공개 후기에 좋아요, 댓글 | |
| 3:30~4:10 | 친구 | user07에서 민트초코에게 친구 요청 → 보낸 요청에서 확인 | 반대 방향 중복 요청은 유니크 인덱스로 차단 |
| 4:10~5:00 | 통계 | user01로 다시 로그인 → 2026년 결산·월별·장르별 | 집계 쿼리를 화면으로. 2026년 6편(영화 4·책 2) |

시간이 모자라면 좋아요·댓글(3:00~3:30)을 빼고, 통계는 user07 화면으로 보여준다.

## 예비 질문 대비
- 배포 DB는 Turso(SQLite 계열). 드라이버가 트랜잭션을 지원하지 않아 문장마다 바로 저장된다.
- 남의 비공개 후기는 번호로 직접 요청해도 404로 막힌다.
- 후기로 '봤어요'가 된 기록은 감상일이 없어 통계에서 빠질 수 있다(버그표 1번).
- 제약조건 질문에는 SQL 캡처(T01~T09)로 답한다.
