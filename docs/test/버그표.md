## 발견한 문제
| # | 심각도 | 위치 | 재현 순서 | 기대 결과 | 실제 결과 |
|---|---|---|---|---|---|
| 1 | 낮(확인 필요) | 통계 | 1) '보고 싶어요' 기록에 후기 작성 2) 트리거가 기록을 '봤어요'로 변경 3) 통계 확인 | 방금 본 작품이 통계에 포함 | 감상일이 비어 있어 통계에서 빠질 것으로 보임. 트리거가 상태만 바꾸고 감상일을 채우지 않고, 통계는 감상일 기준으로 집계함(코드 확인, 배포판에서는 쓰기라 직접 재현 안 함) |
| 2 | 낮 | 공연 외부 검색 | 공연 탭에서 "레미제라블" 검색 | 뮤지컬 레미제라블 | 같은 제목의 다른 공연(구미, 무용)만 나옴. 원인은 추정: KOPIS가 현재·예정 공연만 주는 것으로 보임 |
| 3 | 참고 | 속도 | 사이트 첫 접속 / 외부 검색 | 바로 열림 / 1초 안팎 | 잠든 사이트 깨우는 데 3~4분, 외부 검색 2~3초 (Render 무료 플랜) |
| 4 | 중 | 로그인 유지 | 요청이 몰린 뒤 서버가 느려짐(11초) → 다시 요청 | 로그인 유지 | 401 "로그인이 필요합니다."로 로그인이 풀림. 서버 재시작 때 메모리 세션이 사라진 것으로 추정. 시연 중 풀리면 다시 로그인 |

## 배포판에서 확인하지 못한 것
- 기록 추가·수정, 후기 작성(트리거), 댓글, 외부 작품 가져오기: 앱에서 지울 수 없어 하지 않음 → 리허설에서 확인
- 친구 요청 수락: 다른 계정으로 로그인해야 함
- 가입, 로그아웃 후 재로그인, 로그인 실패 문구: 비밀번호 입력이 필요해 직접 확인 필요
- 다른 사람의 요청 삭제·기록 수정 시 403: 코드에는 검사가 있으나 배포판에서는 실행하지 않음
