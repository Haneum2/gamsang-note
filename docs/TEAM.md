# 팀 역할 분담과 진행 가이드

내부 마감 **11/18**, 제출 **11/19**. 이 문서만 보고 각자 진행할 수 있게 썼다. 막히면 단톡방이 아니라 **GitHub Issue**에 적어도 된다(기록이 남는다).

현재 상태: 앱 기능(기록·후기·친구·통계)은 완성, Oracle에서 검증 완료. 이번 주에 Turso+Render 배포, 자체 가입/로그인, 외부 작품 API(TMDB·카카오 도서) 연동을 개발 담당이 진행한다.

## 공통 규칙
- **비밀번호·토큰·API 키는 저장소, 이슈, 단톡방에 올리지 않는다.** 필요하면 개발 담당에게 개별 전달한다. 이 저장소는 **공개**라서 한 번 올리면 지워도 이력에 남는다.
- 코드(`gamsang-note/`, `gamsang-note-web/`, `db/`)는 개발 담당만 수정한다. 팀원은 자기 폴더(아래)만 수정하고, 코드 문제는 Issue로 알린다.
- 커밋 메시지는 한국어로 짧게. 작업 전 `git pull`, 작업 후 바로 push.
- 매일 저녁 단톡방에 "오늘 한 일 / 내일 할 일 / 막힌 것"을 한 줄씩 올린다.
